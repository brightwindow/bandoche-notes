1아무것도 모르는 사람을 위한 10분

여기만 읽으면 문제 문장이 읽히기 시작한다. 이미 아는 부분은 건너뛰어도 된다.

반도체가 뭔가

전기가 통할지 말지를 우리가 정할 수 있는 물질이다. 구리는 무조건 통하고 유리는 무조건 안 통한다. 실리콘(Si)은 그 중간이라, 손을 대면 통하게도 안 통하게도 만들 수 있다. 그래서 스위치를 만들 수 있고, 그게 반도체의 쓸모다.

전자와 정공 — 두 종류의 운반체

전기가 흐른다는 것은 전하를 띤 무언가가 움직인다는 뜻이다. 반도체 안에서 움직이는 것은 두 가지다.

전자 (electron)

음전하(−)를 띤 진짜 알갱이다. 기호는 n. 갯수를 세면 농도가 된다.

정공 (hole)

전자가 빠져나간 빈자리다. 기호는 p. 빈자리가 옆으로 옮겨 다니면 양전하(+)가 움직이는 것처럼 보인다.

정공이 헷갈리면 이렇게 보면 된다. 극장에 사람이 꽉 찼는데 한 자리가 비었다. 옆 사람이 그 자리로 옮기면 빈자리가 반대쪽으로 한 칸 이동한다. 사람이 움직인 건데 빈자리가 움직인 것처럼 셀 수도 있다. 그 빈자리가 정공이다.

농도의 단위 — cm⁻³

이 과목에서 10¹⁶ cm⁻³ 같은 숫자가 계속 나온다. 가로세로높이 1 cm 짜리 정육면체 안에 몇 개 들어 있나라는 뜻이다. 밀도라고 생각하면 된다.

도핑 — 불순물을 일부러 넣는다

순수한 실리콘에는 캐리어가 거의 없어서 사실상 안 통한다. 그래서 다른 원소를 조금 섞는다. 이것이 도핑이다.

다수 캐리어와 소수 캐리어

도핑을 하면 한쪽이 압도적으로 많아진다. 많은 쪽을 다수(majority), 적은 쪽을 소수(minority)라 부른다.

  • n형 → 다수 = 전자, 소수 = 정공
  • p형 → 다수 = 정공, 소수 = 전자

6장의 모든 식은 소수 캐리어를 따라간다. 다수는 원래 워낙 많아서 조금 늘고 줄어도 티가 안 나기 때문이다. 바다에 물 한 컵을 부어도 바다는 그대로다. 하지만 컵 속 물에게는 전부가 바뀐 것이다.

δ(델타) — 이 장의 주인공

빛을 쬐면 전자와 정공이 늘어난다. 그 늘어난 몫을 δ 로 쓴다.

n = n₀ + δn      p = p₀ + δp 지금 농도 = 원래 있던 것(아래첨자 0) + 빛으로 늘어난 것(δ)

빛알 하나가 전자를 밀어 올리면 그 자리에 빈자리가 남는다. 그래서 반드시 쌍으로 생긴다.

δn = δp

2문제 읽기 — 영어 한 줄씩

문장은 영어지만 쓰이는 단어는 정해져 있다. 조건 하나하나가 뒤에서 식을 지우는 근거가 된다.

6. [40 points] Silicon at T = 300 K has been uniformly doped with arsenic (As) atoms with a concentration of 1016 cm−3.
번역 — 300 K(상온)의 실리콘에 비소(As)를 고르게 1016 cm−3 만큼 도핑했다.
읽어야 할 것 두 가지 — ① As = 5족 → n형 → 소수는 정공(δp)   ② uniformly(고르게) → 어디를 봐도 농도가 같다. 이것이 a) b) c) 에서 확산 항을 지우는 근거다.
a) [10 points] The silicon sample is in thermal equilibrium for t < 0. At t = 0, a light source generating excess carriers is turned on, producing a generation rate of g′ = 1020 cm−3s−1. The minority carrier lifetime is 1 μs. Determine the excess minority carrier concentration for t > 0.
번역 — t < 0 에서는 평형(빛 없음). t = 0 에 빛을 켰고, 생성률은 1020 cm−3s−1 이다. 소수 캐리어 수명은 1 μs. t > 0 의 과잉 소수 캐리어 농도를 구하라.
읽어야 할 것 — thermal equilibrium for t < 0 은 "켜기 전에는 δp = 0 이었다"는 출발 조건이다. 이게 있어야 답의 상수가 정해진다.
b) [10 points] Then, the light source is turned off at t = 10 s. Determine the excess minority carrier concentration for t ≥ 10.
번역 — 그 다음 t = 10 초에 빛을 껐다. t ≥ 10 의 과잉 소수 캐리어 농도를 구하라.
읽어야 할 것 — 빛을 껐으니 g′ = 0. 그리고 시간의 원점이 10 초로 옮겨간다. 지수에 t 가 아니라 (t − 10) 이 들어간다.
c) [10 points] Plot the time-dependent majority and minority carrier concentration (i.e., n(t) and p(t)).
번역 — 시간에 따른 다수와 소수 캐리어 농도 n(t), p(t) 를 그려라.
읽어야 할 것 — δp 가 아니라 n(t) 와 p(t) 를 묻는다. 원래 있던 값(n₀, p₀)을 더해야 한다.
d) [10 points] After a long period of time, the light source illuminates only at x = 0. Determine the steady-state spatial dependence of the excess minority carrier concentration. Assume a zero applied E-field.
번역 — 충분한 시간이 지난 뒤, 빛이 x = 0 한 점에만 비친다. 과잉 소수 캐리어 농도의 정상상태 공간 분포를 구하라. 전기장은 0 이라고 가정.
읽어야 할 것 세 가지 — ① only at x = 0 → 다른 곳은 g′ = 0 ② steady-state → 시간 항이 0 ③ zero E-field → 드리프트 항이 0. 이번엔 확산 항이 살아남는다.

3준비물 — 숫자 두 개

계산에 들어가기 전에 이 둘을 먼저 적어 둔다. 네 문항 내내 쓴다.

1다수 캐리어 — 도핑한 만큼 그대로

As 를 1016 개 넣었으면 전자도 대략 그만큼 생긴다. 원래 있던 것(1010)은 비교가 안 될 만큼 적어서 무시한다.

n₀ ≈ Nd = 1016 cm−3
2소수 캐리어 — 질량작용법칙으로

평형에서만 성립하는 관계가 하나 있다. 전자 농도와 정공 농도를 곱하면 항상 nᵢ² 이다. nᵢ 는 진성 캐리어 농도, 도핑을 안 한 순수 실리콘의 캐리어 농도이고 상온에서 1010 cm−3 이다.

n₀p₀ = nᵢ²  ⟹  p₀ = nᵢ²/n₀ = (1010)²/1016 = 104 cm−3
여기서 정신 차릴 것
n₀ = 10¹⁶ 이고 p₀ = 10⁴ 다. 무려 10¹² 배 차이다.
이 어마어마한 차이가 c) 의 그래프 모양을 통째로 결정한다. 지금 이 숫자를 눈에 새겨 둘 것.

빛을 껐으므로 g′ = 0 이다. a) 에서 남았던 식에서 g′ 까지 지워진다.

g′ − δp/τp0 = ∂(δp)/∂t  ⟹  ∂(δp)/∂t = − δp/τp0

이 식은 "줄어드는 속도가 지금 남은 양에 비례한다"는 말이다. 이런 꼴은 언제나 지수 감쇠 답을 갖는다. 많이 남았을 때는 빨리 줄고, 적게 남았을 때는 천천히 준다.

2출발값을 정한다 — 여기가 이 문항의 핵심

빛을 끈 순간(t = 10 s)에 δp 가 얼마였는지를 알아야 한다. a) 의 답에 t = 10 을 넣어 본다.

δp(10) = 1014 (1 − e−10 / 10−6) = 1014 (1 − e−107)

e−107 은 사실상 0 이다. 수명이 1 μs 인데 10 초를 켜 뒀으니 수명의 천만 배다. 차오를 시간이 넘치도록 있었다는 뜻이라, 이미 완전히 포화돼 있다.

δp(10) = 1014 cm−3
3시간의 원점을 옮긴다

감쇠는 빛을 끈 순간부터 시작한다. 그러니 지수에 들어갈 것은 t 가 아니라 t − 10, 곧 "끄고 나서 얼마나 지났나" 다.

스톱워치를 새로 누른다고 생각하면 된다. t = 10 일 때 지수가 e⁰ = 1 이 되어 δp = 1014 로 이어진다. 만약 t 를 그대로 쓰면 t = 10 에서 이미 e−107 ≈ 0 이 되어 값이 끊긴다.

b) 답 δp(t) = 1014 · e−(t − 10) / 1μs cm−3   (t ≥ 10 s)
이 문항에서 가장 많이 틀리는 곳
지수에 t 를 그대로 쓰는 것이다. 반드시 (t − 10) 이어야 한다.
채점자가 여기를 본다. 나머지가 다 맞아도 이것 하나로 감점된다.

c그래프 그리기  10점 · 슬라이드 5쪽 + 14쪽 Figure 6.7

1묻는 것이 δp 가 아님을 본다

a) b) 는 늘어난 몫(δp)만 구했다. c) 는 전체 농도 n(t), p(t) 를 묻는다. 원래 있던 값을 더해야 한다.

n(t) = n₀ + δn(t)     p(t) = p₀ + δp(t)

그리고 빛은 전자·정공을 쌍으로 만들므로 δn = δp 다. 즉 둘 다 똑같은 양이 더해진다.

2숫자를 넣어 본다 — 여기서 놀라야 정상이다
빛 켜기 전포화된 뒤변화
다수 (전자)n₀ = 10161016 + 1014 = 1.01 × 10161 % 증가
소수 (정공)p₀ = 104104 + 1014 ≈ 10141010 배 증가

똑같이 1014 를 더했는데 결과가 완전히 다르다. 원래 갖고 있던 값이 1012 배 차이 났기 때문이다. 바다에 물 한 컵을 부으면 바다는 그대로지만, 컵 속 물에게는 전부가 바뀐 것이다.

3그래서 세로축을 log 로 그린다

104 과 1016 을 한 그림에 담아야 하는데, 보통 눈금으로는 불가능하다. 104 이 바닥에 붙어 아예 안 보인다.

log 눈금을 쓰면 한 칸이 10 배가 되어 둘 다 보인다. 슬라이드 14쪽 Figure 6.7 이 정확히 그 그림이다.

  • n₀ = 1016, p₀ = 104 값을 축에 적을 것
  • 빛을 끈 뒤 원래 값으로 되돌아간다고 그릴 것 — 0 으로 내려가지 않는다

d한 점에만 빛  10점 · 슬라이드 14쪽 예제 6.4

1이번엔 지워지는 항이 다르다

a) b) 는 시간 문제였고 d) 는 위치 문제다. 조건이 셋이나 붙어 있다.

Dp ∂²(δp)/∂x² − μpE ∂(δp)/∂x + g′ − δp/τp0 = ∂(δp)/∂t zero E-field → 드리프트 = 0  |  x ≠ 0 에서는 빛이 없다 → g′ = 0  |  steady state → 시간 변화 = 0

이번엔 확산 항이 살아남는다. a) b) 와 정반대다.

Dp ∂²(δp)/∂x² − δp/τp0 = 0
2보기 좋게 정리하고 이름을 붙인다

양변을 Dp 로 나눈다.

∂²(δp)/∂x² − δp/(Dpτp0) = 0

분모의 Dpτp0 에 Lp² 이라는 이름을 붙인다. 즉

Lp = √(Dpτp0)    확산거리 (diffusion length) 과잉 캐리어가 사라지기 전까지 평균적으로 퍼져 나가는 거리

왜 이게 거리인지는 단위로 확인된다. D 는 cm²/s, τ 는 s 이므로 곱하면 cm², 제곱근을 씌우면 cm 다. 잘 퍼지고(D 큼) 오래 살수록(τ 큼) 멀리 간다는 뜻이라 직관과도 맞는다.

3푼다

"두 번 미분한 것이 자기 자신에 비례한다"는 꼴이다. 이런 방정식의 답은 지수함수 두 개의 합이다.

δp(x) = A ex/Lp + B e−x/Lp

하나는 오른쪽으로 갈수록 커지고, 하나는 작아진다. 어느 쪽을 버릴지는 상식이 정한다.

4말이 안 되는 항을 버린다

x > 0 쪽에서 ex/L 은 멀어질수록 무한대로 커진다. 광원에서 멀어질수록 캐리어가 많아진다는 뜻이 되므로 말이 안 된다. → A = 0

x < 0 쪽도 같은 이유로 반대 항을 버린다. → B = 0

양쪽을 합치면 절댓값 하나로 쓸 수 있다.

d) 답 δp(x) = δp(0) · e−|x| / Lp,    Lp = √(Dpτp0)

x = 0 을 꼭짓점으로 좌우 대칭으로 줄어드는 뾰족한 산 모양이다. 슬라이드 14쪽 Figure 6.7 아래 그림이 바로 이것이다.

숫자까지 요구하면
6번 문제 자체에는 Dp 가 안 주어져 있으므로 Lp 기호로 두는 것이 정답이다.
다만 같은 시험 5번에 μp = 500 cm²/Vs 가 있으므로, 요구하면 아인슈타인 관계로 넘어갈 수 있다.
Dp = (kT/e)·μp = 0.0259 × 500 = 12.95 cm²/s
Lp = √(12.95 × 10−6) ≈ 3.6 × 10−3 cm = 36 μm

7답안 그대로 옮겨 쓰기

시험지에 이 순서로 쓰면 된다. 지운 이유를 적는 줄이 서술 배점이다.

[공통] As 는 5족 원소이므로 n형 반도체이다. 따라서 소수 캐리어는 정공이고 δp 로 푼다.
n₀ ≈ Nd = 1016 cm−3,   p₀ = nᵢ²/n₀ = 1020/1016 = 104 cm−3
n형 ambipolar transport equation :
Dp∂²(δp)/∂x² − μpE∂(δp)/∂x + g′ − δp/τp0 = ∂(δp)/∂t

(a) uniform 이므로 확산 항 = 0, 전기장이 없으므로 드리프트 항 = 0.
∴ g′ − δp/τp0 = ∂(δp)/∂t
t < 0 에서 평형이므로 δp(0) = 0.
∴ δp(t) = g′τp0(1 − e−t/τp0) = 1014(1 − e−t/1μs) cm−3

(b) 빛을 껐으므로 g′ = 0.
∴ ∂(δp)/∂t = −δp/τp0
τp0 = 1 μs 에 비해 10 s 는 충분히 길어 이미 포화 상태이므로 δp(10) = 1014 cm−3.
∴ δp(t) = 1014·e−(t−10)/1μs cm−3

(c) δn = δp 이므로 n(t) = n₀ + δp(t), p(t) = p₀ + δp(t).
다수 : 1016 → 1.01×1016 (약 1 % 증가로 거의 일정)
소수 : 104 → 약 1014 (1010 배 증가)
두 값의 차이가 커서 세로축을 log scale 로 그린다. 빛을 끄면 각각 1016, 104 로 복귀한다. (그래프 첨부)

(d) 전기장이 0 이므로 드리프트 항 = 0, x ≠ 0 에서 g′ = 0, 정상상태이므로 시간 항 = 0.
∴ ∂²(δp)/∂x² − δp/Lp² = 0,   Lp = √(Dpτp0)
일반해 δp(x) = Aex/Lp + Be−x/Lp 에서 x → ±∞ 에서 발산하면 안 되므로
x > 0 : A = 0,   x < 0 : B = 0
∴ δp(x) = δp(0)·e−|x|/Lp

8자주 틀리는 곳

배점 40점이 갈리는 자리 다섯.

  • As 를 보고 n형을 잡았나 — 여기서 틀리면 δn/δp, Dn/Dp, τ 가 전부 반대로 간다. 40점 전멸
  • b) 지수에 (t − 10) 을 썼나 — 시간 원점 이동. t 를 그대로 쓰면 감점
  • c) 를 log scale 로 그렸나 — 104 과 1016 을 한 그림에 담는 유일한 방법
  • c) 에서 0 까지 내려 긋지 않았나 — 평형값으로 돌아간다
  • 지운 항마다 근거를 한 줄씩 썼나 — 답만 맞으면 반만 받는다
그리고 하나 더 — 예제를 그대로 베끼지 말 것
