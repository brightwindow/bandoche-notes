3과잉 캐리어란

빛알 하나가 들어오면 무슨 일이 일어나는가.

광자(photon, hν) 는 빛알이다. 에너지가 충분히 큰 빛알이 반도체에 부딪히면 아래 띠(가전자띠)에 있던 전자 하나를 위 띠(전도띠)로 밀어 올린다. 이때 전자가 떠난 자리에 빈자리가 남는다. 그 빈자리가 정공이다.

핵심 — 반드시 쌍으로 생긴다
전자 하나가 올라가면 정공 하나가 남는다. 그래서 늘어난 몫이 서로 같다.
δn = δp
이 등식이 6장 전체 유도의 출발점이다.
n = n₀ + δn     p = p₀ + δp 지금 농도 = 원래 있던 것 + 빛으로 늘어난 것
4장 공식이 깨지는 지점
평형에서는 n₀p₀ = nᵢ² 였다. 그런데 비평형에서는
np ≠ n₀p₀ = nᵢ²
질량작용법칙이 성립하지 않는다. 빛을 쬔 상태에서 nᵢ²/n 으로 소수 캐리어를 구하면 틀린다. 이 법칙은 평형에서만 쓸 수 있다.

평형이라고 아무 일도 없는 게 아니다

평형 상태에서도 전자·정공은 계속 생기고 계속 사라진다. 다만 속도가 같아서 겉보기 농도가 안 변할 뿐이다.

Gn0 = Gp0 = Rn0 = Rp0생성률(G) = 재결합률(R)

수도꼭지와 배수구가 같은 속도로 열린 욕조와 같다. 수위는 그대로지만 물은 계속 흐르고 있다. 이 등식은 뒤에서 평형 항을 지우는 근거가 되므로 버리면 안 된다.

4저준위 주입 (low-level injection)

문제에 이 말이 있어야 근사를 쓸 수 있다.

새로 생긴 몫(δ)이 원래 있던 다수 캐리어보다 훨씬 적은 상태를 말한다.

p-type: p₀ ≫ n₀,   p₀ ≫ δn   |   n-type: n₀ ≫ p₀,   n₀ ≫ δp ≫ 는 "압도적으로 크다", 곧 작은 쪽을 버려도 된다는 신호

바다에 물 한 컵 붓기와 같다. 바닷물 양은 사실상 그대로다. 하지만 컵 속 물 입장에서는 전부가 바뀐 것이다. 이 비대칭이 10번 항목의 핵심이 된다.

이 조건이 하는 일
유도 중에 나오는 (δn)² 같은 항을 버릴 수 있게 해 준다. 작은 수의 제곱은 훨씬 더 작기 때문이다. 덕분에 방정식이 손으로 풀 수 있는 형태가 된다. 반대인 high-level injection(δn ~ p₀)에서는 못 버려서 비선형이 되고 손으로 못 푼다.

5수명 τ 와 확산거리 L

6장에 나오는 두 개의 중요한 상수.

τ — 수명 (lifetime)

τn0 = 1 / (αrp₀)

과잉 캐리어가 1/e ≈ 37 % 로 줄어드는 데 걸리는 시간이다. 단위는 초(s)이고 보통 μs 단위다.

다수 캐리어 p₀ 가 많을수록 수명이 짧다. 만날 상대가 많으면 빨리 사라지기 때문이다.

L — 확산거리 (diffusion length)

Lp = √(Dpτp0)

과잉 캐리어가 사라지기 전까지 평균적으로 퍼져 나가는 거리다. 단위는 cm.

잘 퍼지고(D 큼) 오래 살수록(τ 큼) 멀리 간다. 단위 확인: cm²/s × s = cm² → 제곱근 → cm.

재결합률을 수명으로 바꾸는 공식
R′ = δn / τ
뒤에 나오는 모든 방정식에서 재결합 항 자리에 이것을 그대로 넣는다. 외워 둘 것.

6식이 만들어지는 순서

유도를 통째로 쓰라는 문제가 나오면 이 네 단계로 적는다.

  1. 연속방정식 — 아주 작은 상자 하나를 잡고 장부를 쓴다. 은행 계좌와 같다. 입금과 출금을 더하면 잔액 변화다.
    ∂p/∂t = −∂Fp/∂x + gp − p/τpt변화 = 흘러든 것 + 생긴 것 − 사라진 것
  2. 확산방정식 — 위 식의 flux(F) 자리에 5장 전류식을 끼워 넣는다. F = J/e 로 전하량을 알갱이 수로 바꿔서 넣는다. 이때 확산 항이 2차 미분 으로 바뀐다.
    Dp∂²(δp)/∂x² − μpE∂(δp)/∂x + gp − δp/τpt = ∂(δp)/∂t
  3. 둘을 하나로 묶기 — 전자용 식에 μnn, 정공용 식에 μpp 를 곱해 더한 뒤 (μnn + μpp) 로 나눈다.
    D′∂²(δn)/∂x² + μ′E∂(δn)/∂x + g − R = ∂(δn)/∂tambipolar transport equation (양극성 수송 방정식)
  4. 극한 넣기 — 도핑된 반도체 + 저준위 주입 조건을 넣으면 D′, μ′ 가 소수 캐리어 값으로 줄어든다.

왜 둘을 하나로 묶어도 되나

전자는 음전하, 정공은 양전하다. 전기장을 걸어 갈라 놓으려 하면 갈라진 자리에 −와 +가 쌓이고, 그것이 스스로 전기장을 만들어 둘을 도로 끌어당긴다.

E = Eapp + Eint실제로 느끼는 전기장 = 걸어 준 것 + 스스로 생긴 것

고무줄로 묶인 두 사람과 같다. 떼어 놓으려 할수록 줄이 세게 당긴다. 그래서 둘은 붙어서 함께 움직이고, 이동도와 확산계수를 대표값 하나로 뭉뚱그릴 수 있다. 이것이 ambipolar(ambi = 양쪽, polar = 극)라는 이름의 뜻이다.

7최종 방정식 — 이것만 외우면 된다

문제를 받으면 여기서 시작한다. 답안 첫 줄에 도핑 타입을 밝히고 해당 식을 적는 것이 채점 기준이다.

p형 도핑이 3족(B, 붕소) → 다수는 정공, 소수는 전자 → δn 으로 푼다

Dn ∂²(δn)/∂x² + μnE ∂(δn)/∂x + g′ − δn/τn0 = ∂(δn)/∂t

n형 도핑이 5족(P, As) → 다수는 전자, 소수는 정공 → δp 로 푼다

Dp ∂²(δp)/∂x² − μpE ∂(δp)/∂x + g′ − δp/τp0 = ∂(δp)/∂t
둘의 차이는 딱 세 곳
① Dn ↔ Dp   ② δn ↔ δp   ③ 드리프트 항 부호가 + ↔ −
부호가 바뀌는 이유는 양극성 이동도 μ′ = μnμp(p−n)/(μnn+μpp) 의 분자에 (p − n) 이 있어서다. n형이면 n ≫ p 라 음수가 된다.

네 항 읽는 법

항이름뜻
D ∂²(δ)/∂x²확산 (diffusion)진한 데서 옅은 데로 저절로 퍼짐. ∂²/∂x² 는 휘어진 정도. 뾰족할수록 빨리 퍼진다
± μE ∂(δ)/∂x드리프트 (drift)전기장에 밀려 통째로 이동
+ g′생성 (generation)빛으로 새로 생김
− δ/τ재결합 (recombination)전자와 정공이 만나 사라짐
= ∂(δ)/∂t시간 변화결과적으로 얼마나 빨리 변하는가

"시간 변화 = 퍼짐 + 밀림 + 생성 − 소멸" 로 읽으면 된다.

왜 항상 소수 캐리어인가
다수 캐리어는 원래 워낙 많아서 조금 늘고 줄어도 티가 안 난다. 변화를 실제로 좌우하는 것은 소수 캐리어다. 그래서 극한을 넣으면 D′, μ′ 가 언제나 소수 쪽 값으로 줄어든다.

93대 답 패턴

시험에 나오는 답은 사실상 이 세 개뿐이다. 예제 6.2 · 6.3 · 6.4 에 대응한다.

① 빛을 켰다 — 차오름 (예제 6.3)

조건: g′ 일정, 균일, E = 0, t < 0 에 평형(δp(0) = 0)

g′ − δp/τp0 = ∂(δp)/∂t
δp(t) = g′τp0 (1 − e−t/τp0)

욕조로 보면 수도꼭지를 튼 상태다. 물이 차오르다가 들어오는 양과 나가는 양이 같아지면 멈춘다. 포화값이 g′τ 인 이유는 초당 g′ 개가 들어오고 평균 τ 초를 버티기 때문이다.

② 빛을 껐다 — 사라짐 (예제 6.2)

조건: g′ = 0, 균일, E = 0

− δp/τp0 = ∂(δp)/∂t
δp(t) = δp(0) e−t/τp0

지수 감쇠다. 많이 남았을 때는 빨리 줄고 적게 남았을 때는 천천히 준다. e−t/τ 는 τ 만큼 지날 때마다 37 %(=1/e)로 줄어드는 감쇠다.

③ 한 점에만 빛 — 퍼짐 (예제 6.4)

조건: x = 0 에만 생성, 정상상태, E = 0 → 이번엔 시간 항이 지워지고 확산 항이 살아남는다

∂²(δp)/∂x² − δp/Lp² = 0    (Lp = √(Dpτp0))
δp(x) = δp(0) e−|x|/Lp

일반해 Aex/L + Be−x/L 에서 x → ±∞ 로 갈수록 발산하는 항을 버린다. 광원에서 멀어질수록 캐리어가 늘어난다는 것은 말이 안 되기 때문이다. 결과는 x = 0 을 꼭짓점으로 좌우 대칭으로 줄어드는 뾰족한 산 모양이다.

10소수 vs 다수 비대칭

그래프 그리기 문제의 핵심. 같은 δ 가 더해져도 결과가 완전히 다르다.

n형 실리콘에 Nd = 10¹⁶ cm⁻³ 도핑, nᵢ = 10¹⁰ 일 때 δn = δp = 10¹⁴ 만큼 생겼다고 하자.

빛 쬐기 전쬔 후변화
다수 (전자)n₀ = 10¹⁶10¹⁶ + 10¹⁴ = 1.01 × 10¹⁶1 % 증가 — 거의 평평
소수 (정공)p₀ = nᵢ²/n₀ = 10⁴10⁴ + 10¹⁴ ≈ 10¹⁴10¹⁰ 배 폭증 — 수직에 가깝게 치솟음
그래프는 log scale 로
10⁴ 과 10¹⁶ 을 한 그림에 담으려면 세로축을 로그 눈금으로 그리는 수밖에 없다. 눈금 한 칸이 10 배라서 지수함수가 직선처럼 보인다.
그리고 빛을 끄면 원래 값(10¹⁶ 과 10⁴)으로 되돌아간다. 0 으로 가는 것이 아니다.

11Quasi-Fermi 준위

비평형에서는 페르미 준위를 쓸 자격이 없다. 그래서 대신 쓰는 것.

페르미 준위 EF 는 평형에서만 정의되는 값이다. 페르미-디랙 분포 자체가 평형을 가정하고 유도됐기 때문이다. 빛을 쬐는 순간 쓸 수 없게 된다.

해결책은 전자용과 정공용을 따로 정의하는 것이다. quasi 는 "준(準)", 비슷하지만 진짜는 아니라는 뜻이다.

평형비평형
전자n₀ = nᵢ exp[−(EFi−EF)/kT]n₀+δn = nᵢ exp[−(EFi−EFn)/kT]
정공p₀ = nᵢ exp[−(EF−EFi)/kT]p₀+δp = nᵢ exp[−(EFp−EFi)/kT]

식의 모양은 그대로다. EF 하나가 EFn, EFp 둘로 갈라졌을 뿐이다. 계산 방법도 4장과 똑같다.

서술형 단골 — 왜 정공 쪽만 크게 움직이나
n형에 빛을 쬐면 EFn 은 거의 안 움직이고 EFp 만 크게 내려간다. (교재 예제 6.7 에서 전자 쪽 0.0002 eV, 정공 쪽 0.179 eV — 거의 천 배 차이)

이유는 10번 항목 그대로다. 식에 로그가 들어 있어 "몇 배 늘었는지"가 준위 이동을 결정한다. 다수는 1 % 늘어 거의 그대로고, 소수는 10¹⁰ 배 늘어 크게 움직인다.

두 준위가 벌어진 간격이 곧 비평형의 정도다. 평형이면 다시 하나로 합쳐진다.

12SRH 재결합과 표면 효과

실리콘에서 실제로 재결합이 일어나는 방식.

trap(트랩, 덫) 은 원래 전자가 있을 수 없는 금지대 한가운데에 생긴 자리다. 결정이 완벽하면 없는데, 결함(defect) 이나 원자 배열이 어긋나면 생긴다.

실리콘은 indirect(간접) 반도체라 전자가 위에서 아래까지 한 번에 못 떨어진다. 대신 중간의 덫에 잠깐 앉았다가 내려간다. 계단참이 있는 계단과 같다. 이것이 Shockley-Read-Hall(SRH) 이론이고, 실제 실리콘 소자에서 재결합의 주된 경로다.

과정일어나는 일
① Electron capture위 띠의 전자가 덫으로 내려와 앉는다
② Electron emission덫의 전자가 다시 위 띠로 올라간다
③ Hole capture아래 띠의 정공이 덫으로 올라온다
④ Hole emission덫의 정공이 아래 띠로 돌아간다

①과 ③이 이어지면 전자·정공 한 쌍이 사라진다. 그것이 덫을 통한 재결합이다.

표면 효과 (surface states)

결정 내부에서는 원자가 규칙적으로 늘어서 있는데 표면에서는 그 규칙이 뚝 끊긴다. 끊긴 자리의 원자는 결합 상대가 없어 손을 못 잡은 채 남고(dangling bond), 그 자리마다 금지대 안에 준위가 생긴다.

결과적으로 표면에서는 재결합이 내부보다 훨씬 빨리 일어난다. 소자 표면을 산화막으로 덮어 보호하는 이유가 이것이다.

13시험 체크리스트

문제를 받고 답안을 쓰기까지 순서대로.

  • 도핑 원소부터 본다 — 3족(B)이면 p형, 5족(P·As)이면 n형. 여기서 틀리면 대문제가 통째로 날아간다
  • 소수 캐리어를 정한다 — p형이면 전자(δn), n형이면 정공(δp)
  • 해당 최종 방정식을 답안 첫 줄에 쓴다 — 드리프트 항 부호(p형 +, n형 −) 확인
  • 조건 문장을 훑어 항을 지운다 — uniform / steady state / zero E-field / g′=0. 지운 이유를 한 줄씩 쓴다
  • 남은 식을 푼다 — 세 패턴 중 하나로 떨어진다 (차오름 / 사라짐 / 퍼짐)
  • 숫자를 대입한다 — n₀ = Nd, p₀ = nᵢ²/Nd 를 먼저 구해 둘 것
  • 시간 원점을 확인한다 — 도중에 빛을 껐다면 지수에 (t − t₀) 를 쓴다
  • 그래프는 log scale — 다수·소수를 한 그림에 담을 때. 되돌아가는 값은 0 이 아니라 원래 값
자주 하는 실수
① 비평형에서 nᵢ²/n 으로 소수 캐리어 구하기 — 평형에서만 됨
② 다수 캐리어로 식 세우기 — 6장은 언제나 소수 캐리어
③ 예제를 그대로 베끼기 — 교재 예제 6.4 는 p형인데 문제는 n형인 경우가 많다
④ 감쇠 그래프를 0 까지 내리기 — 평형값으로 돌아간다
⑤ 드리프트 항 부호 — n형은 마이너스
